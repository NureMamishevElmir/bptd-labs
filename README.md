# Безпека програм та даних — лабораторні роботи 1–5

ХНУРЕ, кафедра програмної інженерії.
Автор: Мамішев Е. І., гр. ПЗПІ-23-6, варіант 13.

Усі програми написані на C# / .NET 8 (ASP.NET Core) з вебінтерфейсом українською мовою.
Потрібен .NET SDK 8.0 або новіший.

| Папка | Робота | Запуск | Адреса |
|---|---|---|---|
| `LR_1` | ЛР1. Програмна реалізація алгоритму шифрування DES (без готових функцій, перевірка слабких ключів, ECB/CBC, трасування раундів) | `dotnet run --project LR_1/Des.Web` | http://localhost:5101 |
| `LR_2` | ЛР2. Шифрування за алгоритмом RSA (власна генерація простих чисел, обмін браузер ↔ сервер) | `dotnet run --project LR_2/Rsa.Web` | http://localhost:5102 |
| `LR_3` | ЛР3. Власна хеш-функція на 2/4/8 біт, лавинний ефект, автоматичний пошук колізій для docx, коду й png | `dotnet run --project LR_3/Hash.Web` | http://localhost:5103 |
| `LR_4` | ЛР4. Обмін ключами Діффі-Хеллмана, чат для 3+ користувачів (SignalR, AES-GCM), демонстрація MITM | `dotnet run --project LR_4/Dh.Web` | http://localhost:5104 |
| `LR_5` | ЛР5. Платіжна форма: система оплати участі в онлайн-конференціях (LiqPay, тестовий режим) | `dotnet run --project LR_5/ConfPay.Web` | http://localhost:5105 |

У кожній папці є власний `README.md`, модульні тести (`dotnet test`) і звіт `Звіт_ЛРn_Мамішев.pdf`.
Звіти генеруються скриптами з папки `report/` (python-docx, конвертація в PDF через Microsoft Word).
