Програмна реалізація хеш-функцій

ЛР-3 · Безпека програм та даних · Мамішев Е. І., ПЗПІ-23-6, варіант 13

1. Дайджест файлу

2. Лавинний ефект

Випадкові повідомлення 1–256 байт, у кожному змінюється один байт.

3. Колізія

Програма додає nonce у безпечне місце зміненого файлу (docx — XML-коментар, png — чанк tEXt, код — коментар у кінці, інше — байти в кінці), доки дайджести не збіжаться.
