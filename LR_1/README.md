# ЛР №1. Програмна реалізація алгоритму шифрування DES

Дисципліна «Безпека програм та даних», ХНУРЕ.
Виконав: Мамішев Е. І., група ПЗПІ-23-6, варіант 13.

## Що зроблено
- Власна реалізація DES (без `System.Security.Cryptography`): таблиці IP, E, S1–S8, P, PC-1, PC-2, IP⁻¹,
  графік зсувів, 16 раундів мережі Фейстеля; розшифрування — ключі у зворотному порядку.
- Ключ: 8 символів ASCII або 16 hex-цифр; показ ключа з виправленими бітами парності (непарна кількість одиниць у байті).
- Відхилення 4 слабких і 12 напівслабких ключів (порівняння без бітів парності, тож `0000000000000000` теж слабкий).
- Режими ECB і CBC з доповненням PKCS#7; вивід шифротексту в hex і Base64.
- Трасування одного 64-бітного блоку: IP, L0/R0, 16 раундів (kᵢ, Lᵢ, Rᵢ), R16L16, результат.
- Веб-інтерфейс українською мовою.

## Структура
```
Des.sln
Des.Core/   бібліотека: Tables.cs, KeySchedule.cs, WeakKeys.cs, DesCipher.cs, BlockModes.cs, Hex.cs
Des.Web/    ASP.NET Core minimal API (Program.cs) + wwwroot/index.html
Des.Tests/  xUnit-тести (DesTests.cs)
```

## Запуск
```
dotnet run --project Des.Web
```
Відкрити http://localhost:5101

## Тести
```
dotnet test
```
Перевіряються: контрольний приклад `133457799BBCDFF1` / `0123456789ABCDEF` → `85E813540F0AB405`,
раундові ключі та трасування, ECB/CBC на випадкових даних і українському тексті, слабкі та напівслабкі ключі,
біти парності, а також звірка з `System.Security.Cryptography.DES` (лише в тестовому проєкті).
